[Pi](https://pi.dev) extension that replaces the prompt editor with a filled
box. The box has a left accent bar and a status line inside it with the model,
the provider, the thinking level, and a busy indicator.

> [!Warning]
> **Early access**: the look and behavior may still change.

## Install

```bash
pi install npm:pi-tui-prompt-box
```

## Context Footprint

None. The extension only changes the terminal UI: it adds no tools, prompt
sections, or messages to the model context.
