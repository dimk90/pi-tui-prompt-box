### New
* `[ui]` Replace the prompt editor with a filled box and an inner status line
* `[ui]` Take the accent bar and status line colors from the current Pi theme

* `[ui]` Indent Pi's footer by the box margin so it starts in the same column as the box
* `[ui]` Remove the model and provider from Pi's built-in footer; the box shows them
* `[ui]` Show Pi's busy indicators in the status line, including retry and compaction
* `[ui]` Show only the spinner for Pi's default `Working` message
* `[ui]` Indent the chat, queued messages, and widgets by the box margin
* `[ui]` Keep the chat clear of Pi's fullscreen `auto` scrollbar; box and footer align
* `[ui]` Align the autocomplete item text with the input text
* `[ui]` Map mouse clicks on the box to the input text and the autocomplete list
* `[ui]` Indent selectors and extension dialogs shown in place of the box like the chat
* `[ui]` Show Pi's scroll indicators as `N ↑` / `N ↓` in the box padding rows
* `[ui]` Apply Pi's editor `paddingX` setting to the box margins, not the text padding
